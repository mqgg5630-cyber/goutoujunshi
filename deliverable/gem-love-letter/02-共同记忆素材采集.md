# 共同记忆素材采集

> 适用：需要把信写得具体、不像模板时使用。用户素材不足时，按本卷追问。

## 为什么共同记忆比情话重要

大多数失败的情书不是不够深情，而是太像给任何人都能发。共同记忆让对方知道：这封信是写给“你”的，不是写给一个理想对象。

好素材不必宏大，越小越真实：

- 对方说过的一句话；
- 一次下雨、赶车、加班、考试、旅行、吃饭；
- 对方帮忙但没放在心上的小事；
- 一个重复出现的表情、口头禅、笑点；
- 你开始意识到自己心动的瞬间；
- 你看到对方品质的行为证据。

## 素材提问清单

不要一次全问。根据缺口选择 3–6 个：

1. 你们第一次认识时，最记得的画面是什么？
2. 有没有一次对方做了很小但让你一直记得的事？
3. 你是什么时候意识到“不只是朋友/不只是习惯”的？
4. 你喜欢对方哪些具体行为，而不是抽象品质？
5. 你们之间有没有共同梗、昵称、地点、歌、照片、物件？
6. 如果对方读完只记住一句，你最想 TA 记住什么？
7. 你希望对方有什么压力？答案应该是“越少越好”。
8. 你能接受什么结果？愿不愿意在拒绝后体面后退？

## 素材转写公式

### 公式一：行为 + 感受 + 意义

```text
你当时【具体行为】，我其实一直记得。那一刻我感觉【感受】，后来才发现，它让我越来越确定【意义】。
```

示例：

```text
你那天只是顺手把我没说完的话接住了，可能你自己都不记得。但我一直记得，因为那一刻我第一次觉得，原来有人不用我解释很多，也能听懂我在意什么。
```

### 公式二：小事 + 反复出现 + 关系变化

```text
一开始我以为只是【小事】，后来这种感觉反复出现：每次【场景】，我都会【反应】。到后来我才承认，我对你的在意已经超过了朋友。
```

### 公式三：共同梗 + 认真落点

```text
我们总拿【共同梗】开玩笑，但我想认真说的是，它背后其实是我和你相处时最喜欢的感觉：轻松、被接住、不需要表演。
```

## 素材筛选

优先选择：

- 对方看了会想“你居然记得这个”；
- 不暴露对方隐私；
- 不让第三人难堪；
- 能体现对方的行为，而不是单纯外貌；
- 既有温度，也能支撑“我为什么喜欢你”。

避免选择：

- 只有用户单方面过度解读的细节；
- 对方已经表示尴尬或不想再提的事；
- 私密到不适合写进截图可传播文字的内容；
- 用来证明“你欠我”的付出记录。

## 素材不足时的替代

如果用户没有共同记忆，不要硬写深情长信。可改成：

```text
我们认识还不算很久，所以我不想把话说得太满。但这段时间和你聊天，我确实越来越期待了解你。与其写一大段让你有压力的话，不如认真问你一次：这个周末愿不愿意和我单独吃个饭？
```

素材不足说明关系也可能还没到长信阶段。诚实比强行煽情更好。
