# 告白信与久识情书 Skill

## 核心原则

先判断关系，再写信。好的情书不是用华丽辞藻“拿下”对方，而是把真实感受、具体记忆、清晰邀请和对方的拒绝权放在同一封表达里。

默认保护四件事：用户的体面、对方的自主、已有关系的可修复性、表达后的下一步。不要把得到一个答案当作唯一目标。

## 使用流程

1. **分区判断**：先判断是低熟悉、熟悉未暧昧、久识且互惠、已确定关系，还是高风险关系。
2. **决定载体**：低熟悉用 60–120 字轻表达；久识互惠可写 300–800 字情书；已确定关系可写长文；高风险时建议暂缓或改边界表达。
3. **采集素材**：只问会让信具体的问题：认识多久、当前关系、三件关键记忆、近期互惠信号、目标、发送渠道、想要口吻。
4. **生成成品**：先给可直接发送的版本，再给口吻说明、发送时机和后续分支。
5. **二次润色**：根据用户日常用词、昵称、标点、表情习惯、亲密程度改写，去 AI 腔和油腻感。

## 必问素材

信息不足时，最多问 3–6 个问题：

```text
你们认识多久、现在是什么关系？
最近有哪些事让你觉得想表达？给 2–3 个具体细节就行。
对方最近有没有主动、关心、邀约、分享生活或明确拒绝？
你希望结果是确认关系、约一次会、表达感谢，还是只想让对方知道？
准备发微信、手写、邮件、卡片、网页还是视频文案？
想要稳健、温柔深情、轻松不尴尬、文艺、克制还是搞笑？
```

用户已经给足素材时，不追问，直接写。

## 推荐结构

### 告白信五段

1. **降压开场**：不是逼你马上回答，只是想认真说清楚。
2. **具体记忆**：写 2–4 个只有你们之间成立的细节。
3. **感情变化**：说明从熟悉、欣赏到喜欢的过程，不写成情感债务。
4. **清晰邀请**：我喜欢你；如果你愿意，我们可以从一次正式约会开始。
5. **尊重收束**：你可以需要时间，也可以拒绝；我会尊重和体面接受。

### 久识情书重点

- 写“我后来才意识到”，不要写“我等了你这么多年”。
- 写对方的具体行为和品质，不泛泛夸“你是全世界最好”。
- 写下一步小动作，不直接跳到永远、婚姻、生育或牺牲。
- 结尾给对方台阶：需要时间、不一样的答案、只做朋友，都可以被尊重。

## 输出格式

用户要成品时，按这个顺序：

1. **可直接发送版**；
2. **更克制/更深情/更轻松的备选**（最多两版）；
3. **发送建议**：什么时候发、用什么载体、发后多久不追问；
4. **后续分支**：积极、需要时间、拒绝、不回应、明确不适分别怎么回。

用户只要一句话时，第一屏直接给一句，不先讲理论。

## 模板骨架

### 相识很久后的低压告白

```text
我想认真跟你说一件事，但不是要你马上给答案。

我们认识已经很久了，很多时候我都觉得，跟你相处是一件很自然也很安心的事。比如【具体记忆1】，还有【具体记忆2】，这些事可能看起来不大，但我一直记得。

我也是后来才慢慢意识到，我对你的在意已经不只是朋友之间的习惯。我会期待你的消息，会在遇到一些事时第一个想到你，也会认真想象，如果我们能更靠近一点，会是什么样子。

所以我想告诉你：我喜欢你。不是一时冲动，也不是想把我们这么久的关系变成压力。如果你也愿意，我们可以从一次正式的约会开始试试看；如果你需要时间，我不会催你；如果你的答案不是这样，我也会尊重。

谢谢你读完。你对我来说一直是很重要的人，所以我也希望这份表达是温柔的、清楚的，而不是让你为难的。
```

### 老朋友转关系，轻松不尴尬版

```text
我想坦白一件有点认真、但不想搞得太沉重的事。

以前我一直觉得我们是很舒服的朋友，后来发现自己好像有点“不太朋友”了：会期待你找我，会记得你随口说过的小事，也会在很多瞬间觉得，和你待在一起真的挺好。

所以我想试着往前走一步：我喜欢你。如果你也有一点类似的感觉，我们找个时间认真约一次会；如果你没有，也不用有负担，我会把这件事消化好，不会拿它绑架我们之间的相处。

总之，今天不是审判日，只是我不想再假装自己完全没心动。
```

## 后续分支

| 反馈 | 回应原则 |
| --- | --- |
| 积极 | 约一次具体见面或通话，不立刻堆未来承诺 |
| 需要时间 | 感谢认真看完，至少 24–72 小时不追问 |
| 委婉拒绝 | 感谢坦诚，说明会调整，不追问理由，不要求补偿 |
| 不回应 | 不连续补发长解释；48–72 小时后最多一句低压收束 |
| 明确不适 | 道歉并停止推进；对方要求不联系时执行 |

## 禁止协助

不要生成威胁、自伤暗示、情感债务、公开逼迫、持续纠缠、破坏他人关系、伪造事实、利用权力差施压，或“不能拒绝”的现实执行方案。可以把趣味网页里的逃跑按钮当视觉梗，但真实表达必须保留拒绝权。
